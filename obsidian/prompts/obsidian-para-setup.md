# Развернуть базу знаний: PARA-структура и `CLAUDE.md`

> Инструкция одинаковая для Windows, macOS и Linux: агент сам определяет систему.

**Когда:** после занятия 6, дома. Obsidian к этому моменту должен быть установлен:
скачать бесплатно с [obsidian.md](https://obsidian.md/). Если база у вас уже есть, промпт
всё равно можно запустить: он достраивает недостающее, а существующее не трогает.
**Что делает:** создаёт папку хранилища (vault) с пятью папками PARA, кладёт в корень
`CLAUDE.md` с правилами для агента и файл `.gitignore` (пригодится на следующем шаге).
**Как использовать:** откройте VS Code в вашей рабочей папке (той же, где лежат проекты
курса), запустите Claude Code и отправьте промпт ниже. Если агент спросит, где вы хотите
держать базу: ответьте полным путём, это нормальный ход, а не сбой.

> Vault это просто папка на диске. Obsidian не хранит заметки внутри себя: он открывает
> папку и показывает `.md`-файлы из неё красиво. Поэтому структуру можно создать до того,
> как вы вообще откроете Obsidian: он подхватит готовое.

```text
Помоги мне развернуть базу знаний в Obsidian по системе PARA.

Работай по полным (абсолютным) путям и на каждом шаге показывай, что получилось.
Ничего существующего не удаляй и не перезаписывай без моего подтверждения.

1. Определи мою операционную систему.

2. Спроси меня, где я хочу держать базу знаний и как её назвать, и предложи разумный
   вариант по умолчанию: папка внутри домашней папки, например "Obsidian" или
   "Мой второй мозг". Дождись моего ответа, путь сам не выдумывай.
   Если папка с таким именем уже существует и в ней есть .md-файлы: не создавай новую,
   а работай с ней: скажи мне, что нашёл существующую базу, и достраивай недостающее.

3. Создай внутри неё структуру PARA:
   00-Inbox      - входящие, необработанное
   01-Projects   - активные проекты с результатом и сроком
   02-Areas      - зоны ответственности
   03-Resources  - справочные материалы по темам
   04-Archive    - завершённое и неактуальное
   attachments   - картинки и вложения
   Templates     - шаблоны заметок

   В каждую папку положи пустой файл .gitkeep: иначе пустые папки не попадут в git
   на следующем шаге.

4. Создай в корне базы файл CLAUDE.md это инструкция для тебя же, ты будешь читать её
   при каждом запуске в этой папке. Опиши в нём:
   - структуру папок из пункта 3 и что в какую класть
   - конвенцию: все заметки в формате markdown (.md)
   - конвенцию: связи между заметками через двойные квадратные скобки [[Название]]
   - конвенцию: при создании заметки сначала проверить, нет ли уже похожей
   - конвенцию: язык заметок русский, названия инструментов и аббревиатуры (API, MCP)
     оставлять как есть
   - правило: если непонятно, куда положить заметку, класть в 00-Inbox
   Пиши CLAUDE.md как набор инструкций для агента, а не как описание для человека.

5. Создай в корне базы файл .gitignore со следующим содержимым:
   .obsidian/workspace.json
   .DS_Store
   **/.DS_Store
   Thumbs.db
   *.mp4
   *.mp3
   *.mov
   *.wav

6. Создай в 00-Inbox первую заметку "Проверка связи.md": пара строк о том, что база
   развёрнута, сегодняшняя дата, и ссылка вида [[Проверка связи]] на саму себя, чтобы
   я увидел, как выглядит вики-ссылка.

7. Покажи мне полный путь к базе и итоговое дерево папок. Напомни, что дальше надо
   открыть Obsidian и выбрать "Открыть папку как хранилище", указав этот путь.
```

---

## Как понять, что получилось

1. Откройте Obsidian → **Открыть папку как хранилище** (`Open folder as vault`) → укажите
   путь, который назвал агент.
2. Слева в дереве должны быть все пять папок с цифрами в начале, по порядку.
3. Откройте `00-Inbox/Проверка связи.md`: увидите заметку.
4. Нажмите на иконку графа в левой панели (или `Cmd+P` / `Ctrl+P` → `Graph view`).
   Пока там одна точка. Через полгода будет сеть.

Файлы `CLAUDE.md`, `.gitignore` и `.gitkeep` в дереве Obsidian не отображаются: это
нормально, Obsidian показывает только заметки. Проверить их наличие можно в VS Code
или спросив у агента.
