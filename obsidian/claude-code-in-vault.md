# Claude Code внутри базы знаний

> Vault это папка. Значит, для агента это такой же проект, как ваш лендинг.
> Со своим `CLAUDE.md`, своими правилами и своими рабочими сценариями.

---

## Как открыть

Ровно так же, как проект: VS Code → `Файл` → `Открыть папку` → выбрать папку vault →
запустить Claude Code.

С этого момента агент видит все ваши заметки. Он может искать по ним, читать, править,
создавать новые и связывать их между собой.

⚠️ **Отдавайте себе отчёт:** файлы, к которым обращается агент, уходят на серверы
Anthropic. Для личной базы знаний это обычно нормально, но если в vault лежат чужие
персональные данные, коммерческая тайна или что-то, чего вы не хотели бы отправлять
наружу, держите это в отдельной папке и не открывайте её агентом.

## `CLAUDE.md` в корне vault

Файл, который агент читает автоматически при каждом запуске. Без него на каждую заметку
придётся заново объяснять, где какая папка и на каком языке писать.

Вот рабочий пример: можно скопировать целиком и поправить под себя:

````markdown
# Моя база знаний: Obsidian Vault

## Структура (PARA)

```
├── 00-Inbox/     - входящие заметки, необработанное
├── 01-Projects/  - активные проекты с конкретным результатом
├── 02-Areas/     - зоны ответственности (работа, здоровье, финансы, техника)
├── 03-Resources/ - справочные материалы по интересам и темам
├── 04-Archive/   - завершённые проекты и неактуальное
├── attachments/  - картинки и вложения
└── Templates/    - шаблоны заметок
```

## Конвенции

- Все заметки: markdown (.md)
- Связи между заметками: через [[wiki-ссылки]]
- При создании или правке заметки: всегда связывать с существующими через [[Название]]
- Непонятное и необработанное: в `00-Inbox/`
- Язык: русский. Названия инструментов и общепринятые аббревиатуры оставлять
  как есть (API, MCP, SEO)

## Когда создаёшь новую заметку

1. Сначала проверь, нет ли уже похожей: не плодить дубликаты
2. Проставь [[wiki-ссылки]] на связанные заметки
3. Одна заметка: одна идея
4. Если заметка про источник (книга, статья, видео): указать автора, название и URL
5. В начале файла: frontmatter: теги, дата, источник
````

Обратите внимание на последний блок: это не описание, а инструкции. `CLAUDE.md`:
не документация для человека, а правила для агента.

## Индекс: зачем он нужен

В базе преподавателя 524 заметки. Чтобы найти, с чем связать новую, агенту пришлось бы
открыть все 524 файла. Долго и дорого.

Поэтому в корне лежит `_VAULT_INDEX.md`: по одной строке на заметку:

```
## 🤖 AI / Claude Code

[[Claude Code: конфигурационные файлы]] #ai #claude-code #resource
[[MCP: подключение внешних инструментов]] #ai #mcp #resource
[[Харнес: обёртка над моделью]] #ai #resource
```

Весь индекс это один файл, который агент читает целиком за раз. Дальше он видит
темы и теги всей базы и подбирает связи осмысленно.

Собирается автоматически скриптом внутри скилла, руками не редактируется. На старте,
пока заметок два десятка, индекс не нужен: он начинает окупаться где-то после сотни.

## Что реально просят у агента в базе знаний

Пять сценариев, которые работают с первого дня.

### Сделать заметку из источника

```
https://www.youtube.com/watch?v=T6Mfl1OywM8

Сделай заметку в Obsidian.
```

Агент вытянет субтитры, переведёт, структурирует, положит в нужную папку, проставит
ссылки. Работает для видео, статей, GitHub-репозиториев. Механика: в
[skill-example/SKILL.md](skill-example/SKILL.md).

### Найти по смыслу, а не по слову

```
Найди в базе всё, что я записывал про работу с промптами.
Собери одной сводкой: что повторяется, что противоречит друг другу.
```

Поиск Obsidian ищет по вхождению строки. Агент ищет по смыслу и сразу делает выводы.

### Разобрать Inbox

```
Разбери 00-Inbox: по каждой заметке скажи, в какую папку PARA она относится
и почему. Ничего не перемещай, сначала покажи список.
```

«Сначала покажи список»: важная часть. Дайте агенту разложить всё сразу, и вы
потеряете контроль над тем, что куда уехало.

### Связать то, что живёт по отдельности

```
Посмотри заметки в 03-Resources/AI. Найди, между какими нет вики-ссылок,
хотя они про одно и то же. Предложи, что с чем связать.
```

Так граф перестаёт быть россыпью точек и становится сетью.

### Написать ретроспективу

```
Напиши в 01-Projects заметку-ретроспективу по занятию 5:
что строили, что получилось, где я застрял. Спроси меня, если чего-то не хватает.
```

Это, кстати, домашнее задание к занятию 5.

## Одно правило, которое стоит держать в голове

Агент отлично формулирует, структурирует и связывает. Но заметка, которую вы не
прочитали и не поправили своими словами, при перечитывании через полгода не даст
ничего: вы её не помните, потому что не думали над ней.

Разумное разделение: агент делает черновую работу: вытянуть, перевести, разложить,
связать. Вывод в конце заметки пишете вы сами. Одна фраза «зачем мне это» превращает
конспект в знание.
