# Скилл «сделай заметку»: как поставить и как он устроен

> Готовый пример скилла из занятия 4: только теперь боевой, а не учебный.
> Он же: половина ответа на домашнее задание «напиши свой скилл».

---

## Что он делает

Вы кидаете в чат ссылку и говорите «сделай заметку в Obsidian». Дальше без вас:
агент понимает, что это за источник, вытягивает содержимое, пересказывает по-русски,
раскладывает по структуре, проставляет вики-ссылки на связанные заметки и кладёт файл
в нужную папку vault.

Разница ощущается на длинных источниках. Часовое видео → конспект на страницу за
минуту. Без скилла тот же результат требует пяти-шести сообщений с уточнениями
каждый раз.

---

## Глобальный или проектный

Скилл можно положить в двух местах, и это разные вещи:

| Куда | Путь | Когда работает |
|---|---|---|
| **Глобально** | `~/.claude/skills/obsidian-note/SKILL.md` | В любом проекте, в любой папке |
| **В проект** | `<папка проекта>/.claude/skills/obsidian-note/SKILL.md` | Только внутри этого проекта |

Для заметок в Obsidian нужен **глобальный**. Смысл в том, чтобы кинуть ссылку из
любой сессии: вы работаете над лендингом, наткнулись на статью, сохранили её в базу
и вернулись к лендингу. Проектный скилл в такой момент недоступен, потому что вы не
в папке vault.

На Windows домашняя папка это `C:\Users\ВашеИмя`, то есть путь будет
`C:\Users\ВашеИмя\.claude\skills\obsidian-note\SKILL.md`.

---

## Установка

**1. Скопировать файл.** Возьмите [SKILL.md](SKILL.md) из этой папки и положите по
пути `~/.claude/skills/obsidian-note/SKILL.md`. Имя папки должно совпадать с полем
`name` внутри файла.

**2. Подставить свой путь к vault.** В начале файла два плейсхолдера
`/ПОЛНЫЙ/ПУТЬ/К/ВАШЕМУ/VAULT`: замените на реальный путь. Не помните точный путь?
Спросите у агента: «покажи полный путь к папке моего Obsidian vault».

**3. Перезапустить VS Code.** Скиллы подхватываются при старте: без перезапуска
Claude Code его не увидит.

**4. Проверить.** В чате:

```
/skills
```

`obsidian-note` должен быть в списке. Если его нет, почти всегда дело в одном из
трёх: не совпадает имя папки с `name`, сломан frontmatter (первые строки между `---`),
или VS Code не перезапускали.

**5. Испытать на живой ссылке.** Киньте в чат ссылку на любую статью и напишите
«сделай заметку в Obsidian». Заметка должна появиться в vault, а не в текущей папке.

---

## Как он вызывается

Никаких команд. Вы просто пишете естественную фразу, а Claude сам решает, что подходит
скилл. Работает благодаря полю `description` в шапке файла:

```yaml
description: "Создаёт оформленную заметку в Obsidian vault из источника: статья,
YouTube-видео, GitHub-репозиторий или тема без ссылки. Использовать когда пользователь
говорит: сделай заметку, сохрани в Obsidian, добавь в базу, законспектируй, изучи и запиши."
```

Вторая половина описания: перечисление живых фраз. Это самая важная строка во всём
файле: по ней агент понимает, что вы обращаетесь именно к этому скиллу. Расплывчатое
описание вроде «работа с заметками» не сработает: скилл просто не подхватится.

Когда будете писать свой скилл для домашнего задания, начните именно с `description`,
а не с инструкций.

## Чем боевая версия отличается от этой

Версия, которую вы видели на экране, крупнее раза в три. Что в ней есть сверх:

- **Индекс базы.** Файл `_VAULT_INDEX.md` с одной строкой на каждую из 524 заметок.
  Агент читает его целиком вместо того, чтобы перебирать папки, и подбирает связи
  осмысленно. Плюс отдельный скрипт, который этот индекс пересобирает.
- **Поиск связей отдельным дешёвым агентом.** Подбор вики-ссылок отдаётся субагенту
  на модели Haiku: задача механическая, гонять на ней Opus незачем. Тот самый приём
  «выбор модели под задачу».
- **Эмодзи в начале имени файла.** `🏇🏼 Харнес`, `🪓 Git worktree`: визуальные якоря,
  по которым файл цепляется взглядом в списке и в графе. Грабля: эмодзи ломает
  вики-ссылки, потому что Obsidian ищет файл по точному имени. Лечится полем
  `aliases` во frontmatter, куда пишется имя без эмодзи.
- **Карты содержания.** Файлы вида `_index Тема.md`: оглавление по крупной теме,
  когда заметок в ней стало слишком много.

Всё это выросло не сразу, а по мере того, как база пухла. Начинать с такой сложности
не надо: поставьте простую версию, поживите с ней месяц и дорастите под себя то, чего
не хватит.
