# Занятие 6: раздатка

Сегодня учимся проверять то, что построил агент, и автоматизировать то, что повторяется.
Пишем свою команду `/review` и гоняем её по лендингу и MVP, чиним найденное и выкатываем.
Смотрим, куда девается всё, что мы пишем в `.md`: база знаний в Obsidian. Ставим первый хук,
который срабатывает сам, без напоминаний. И одеваем проект в дизайн-систему известного бренда.

Дорога курса: **найти идею → обсудить её → дать себя допросить → записать → разбить на задачи
→ делать по одной.** Сегодня к шагу «делать» добавляется шаг «проверять».

## Сначала проверка

В VS Code открой папку `work/StartUp/landing` и попроси Claude Code:

```text
Покажи открытые и закрытые тикеты спеки MVP на GitHub и ссылку, по которой открывается лендинг.
```

Тикетов нет совсем? Вернись к раздатке
[занятия 5](https://github.com/ahtlv/claude-course-lesson-5): без спеки и тикетов ревью
не на чем строить.

## Промпты по порядку

| Шаг | Промпт | Что делает |
|---|---|---|
| 1 | [`review-command.md`](prompts/review-command.md) | Своя slash-команда `/review`: проверяет страницу и возвращает список проблем, ничего не правя |
| 2 | `/review` по лендингу и MVP | Мелочь чиним по одному пункту, крупное заводим тикетом, выкатываем |
| 3 | [`sound-hook.md`](prompts/sound-hook.md) | Первый хук: звук, когда агент закончил работу |
| 4 | [`design-system.md`](prompts/design-system.md) | Дизайн-система на лендинг и MVP: агент предлагает три, ты выбираешь |

Промпты работают одинаково на Windows, macOS и Linux: агент сам определяет систему. На Windows
терминал только `cmd`, если открылся PowerShell, переключись.

## Что ещё в раздатке

- [`slash-commands/`](slash-commands/README.md): десять готовых команд. Начни с трёх:
  `/explain` (объясни, что тут написано), `/backup` (точка возврата), `/ship` (выложи в интернет).
- [`hook-recipes.md`](hook-recipes.md): ещё четыре хука, каждый одним промптом.
- [`obsidian/`](obsidian/README.md): база знаний, которую читает агент. Система папок PARA,
  синхронизация с GitHub, скилл «кинул ссылку, получил заметку».

## Домашнее задание

**К занятию 7, обязательно: доводим лендинг до вида, который не стыдно показать.**

1. Примерь три дизайн-системы промптом [`design-system.md`](prompts/design-system.md), выбери
   одну и примени к лендингу.
2. Ещё раз прогони `/review`: телефон, тексты, кнопки.
3. Задеплой: страница открывается по ссылке.
4. MVP: один-два следующих тикета через `implement`, каждый в новой сессии. Промпт
   [`first-ticket.md`](https://github.com/ahtlv/claude-course-lesson-5/blob/main/prompts/first-ticket.md)
   с занятия 5.

В чат курса: ссылка на лендинг и скриншот «до/после».

**Для желающих:**

- ⭐ Покажи лендинг и MVP трём живым людям, лучше из тех, для кого он задуман. Не помогай,
  слушай. Отзывы надиктуй агенту: «разложи эти отзывы на тикеты в спеку MVP». На занятии 7
  эти тикеты пригодятся.
- ⭐ Своя slash-команда под то, что ты повторяешь в чате чаще всего.
- ⭐ Второй хук из [рецептов](hook-recipes.md).
- ⭐ Разверни Obsidian: [PARA](obsidian/prompts/obsidian-para-setup.md) и
  [синк с GitHub](obsidian/prompts/obsidian-github-sync.md). Напиши туда ретроспективу курса:
  что строил, что получилось, что было сложно.

## Если что-то не получается

Пиши в чат курса. Скриншот того, что видишь на экране, помогает быстрее любого описания.
